Watch messy branch data get fixed

When a retailer grows branch by branch, the same product gets recorded in different ways and the profit report goes wrong. Here are 3,840 practice sales lines from 12 branches. Try it in three clicks.

  1. Click Load the data to see the mess.
  2. Click the green Clean it button and watch the profit margin and the "Unmapped" sales change at each step.
  3. Click Load the data again to see exactly what was fixed.

What's wrong
  • The same product's code is written different ways
  • Some quantities are in dozens or litres, not items
  • A price was keyed ten times too high
  • Some codes don't exist, and some quantities are negative
  • The system's cost is out of date for 8 products

Cleaning, one step at a time

Profit margin = (sales − cost) ÷ sales. Each step fixes one kind of mistake and the report is worked out again.

The same data, after cleaning

Green cells were fixed, with the old value underneath. Amber lines can't be fixed safely, so they go to a person.

Some code typos land on a different real product, so they look valid and rules can't catch them. The next rule to add is a check against each product's typical price. Real data is messier than this, so on real files I would tune the rules first.

How this would run inside Naivas's systems

It sits between the branch systems and the reports, so nothing in the tills or the ERP has to change. A good way to begin is a pilot on a few branches, then roll out to the rest.
